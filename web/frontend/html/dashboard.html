Platform Overview

🎯 Product Scope

  • Capture images from mobile or web camera
  • Mark object regions with box, circle, or polygon tools
  • Predict object distance and area using AI
  • Render distance/area labels on images
  • Feed validated samples back to training pipeline

🏗️ Architecture

  • API Gateway: Centralized request routing
  • Inference Orchestrator: Model prediction coordination
  • Model Service: Distance/area estimation engine
  • Annotation Service: Storage and retrieval of labeled data
  • Dataset Service: Training data pipeline management
  • Auth Service: Token-based authentication

⚙️ Technology Stack

  • Backend: FastAPI, Python, microservices
  • Frontend: HTML5 Canvas, Vanilla JavaScript
  • ML: Baseline model training & evaluation
  • DevOps: Docker, docker-compose, CI/CD ready
  • API: OpenAPI/Swagger contract-first design
