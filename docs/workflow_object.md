# Workflow Object Map

## Main Objects
- ImageObject
  - image_id
  - image_uri
  - source
  - captured_at

- AnnotationObject
  - mark_type
  - box or polygon
  - true_distance_cm

- PredictionObject
  - distance_cm
  - confidence
  - label_position
  - model_version

- DatasetBatchObject
  - source
  - dataset_name
  - version
  - records
  - job_id

## Object Lifecycle
1. ImageObject created by mobile capture.
2. AnnotationObject generated by marking tool.
3. PredictionObject returned from inference flow.
4. DatasetBatchObject registered for training feed.

## Service Ownership of Objects
- annotation_service: AnnotationObject
- inference_orchestrator: PredictionObject composition
- dataset_service: DatasetBatchObject
- model_service: raw prediction values
